# Student Behaviour Analysis

A web-based Student Behaviour Analysis system that uses student-related data to analyze behaviour patterns and generate predictions.

## 📌 Project Overview

The Student Behaviour Analysis system is designed to help analyze student behaviour using academic and behavioural information.

Users can enter student-related information, generate a behaviour prediction, and store the prediction data in a database. The dashboard displays previously recorded prediction results for analysis.

## 🚀 Features

* Student behaviour prediction
* User-friendly prediction form
* Machine learning-based analysis
* Database storage for prediction results
* Dashboard to view prediction records
* Student data analysis
* Responsive web interface

## ⚙️ Installation

Clone the repository:


git clone YOUR_GITHUB_REPOSITORY_URL

Go into the project directory:

cd student-behaviour-analysis

Create a virtual environment:

python -m venv venv


Activate the virtual environment.

### Windows


venv\Scripts\activate

### macOS/Linux

source venv/bin/activate

Install the required packages:

pip install -r requirements.txt

Run the application:

python app.py

Open the application in your browser using the local URL shown by Flask.

## 📊 How It Works

1. User opens the Student Behaviour Analysis system.
2. Student information is entered into the prediction form.
3. The machine learning model processes the input.
4. A behaviour prediction is generated.
5. The prediction is stored in the database.
6. The dashboard displays the saved prediction records.

## 🎯 Purpose

The project demonstrates how machine learning can be integrated with a web application and database to create a practical student behaviour analysis system.
